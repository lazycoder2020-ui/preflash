Use it on your machine

The same checks as a command-line tool. No account, no dependencies.

pip install git+https://github.com/lazycoder2020-ui/preflash
preflash path/to/project

Found a password?

Deleting it from the code isn't enough if it was ever pushed to GitHub. Change the password or rotate the key, then keep secrets in a git-ignored arduino_secrets.h.
