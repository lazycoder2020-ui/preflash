Scan your ESP32 / Arduino sketch before you flash it.

I scanned 249 public ESP32 and ESP8266 projects on GitHub. About 1 in 5 had a home Wi-Fi password sitting in the code, plus Blynk and Telegram tokens, open OTA updates and setInsecure() everywhere. The usual secret scanners missed nearly all the Wi-Fi passwords, so I wrote this.

Paste your code or drop your project folder in. It all runs in this tab. Nothing gets sent anywhere.

Found something?

If the code was ever pushed to GitHub, change that password or rotate the token. Deleting the line doesn't remove it from git history. Then move secrets into an arduino_secrets.h and add it to .gitignore.

Run it locally

Same checks, from the terminal. No account, no dependencies.

pip install git+https://github.com/lazycoder2020-ui/preflash
preflash path/to/your/project

· there's also a GitHub Action and a pre-commit hook in the README.
